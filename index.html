02 / selected systems

Systems I've taken from proposal to production

Built at Apple Holidays Destination Services. Each one as a short case study; the graph follows along.

SYS‑01AI engineering · MCP

Conversational booking over MCP

Problem
Travel agents had to click through the portal for every flight search, fare comparison, booking and post‑booking change.
What I built
An in‑house MCP server exposing the full system surface as agent tools, on a shared Node.js agent core with isolated agent contexts and permission boundaries, reached over WhatsApp, email, voice and web chat.
In production
Retry and idempotency for tool calls, conversation state persisted across channels, failure isolation between agents, and memory and cost tuning on constrained infrastructure.
  • Node.js
  • MCP
  • OpenAI
  • Laravel
  • Redis
SYS‑02AI engineering · automation

Autonomous supplier outreach & ingestion

Problem
Supplier rates and contract details were collected by hand, then typed into the inventory system.
What I built
An outreach agent that contacts suppliers by AI voice call (ElevenLabs), WhatsApp (Meta Business API) and email (Microsoft Graph), collects rates and contract details, and chases what's missing. A document‑ingestion agent parses arbitrary contract files and writes products and rates to the database.
Outcome
Rates sync live to the booking platforms, with no manual collection or data entry.
  • Laravel
  • MCP
  • ElevenLabs
  • WhatsApp API
  • MS Graph
SYS‑03travel platform · white‑label

B2B ticketing platform

Problem
One platform had to serve several branded operators, with more than 150 live travel agents actively using it.
